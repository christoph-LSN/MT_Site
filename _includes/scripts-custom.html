{%- comment -%} Custom scripts for the MT_Site implementation. Open SDG automatically injects this include near the closing tag. This makes it the recommended place for project-specific JavaScript that should run after the main page content has been rendered. In this project we use it to load: 1) leaflet.browser.print - third-party Leaflet plugin used to create a print control for maps 2) map-print.js - project-specific integration layer that: * finds the visible Open SDG / Leaflet map * adds the print button * builds the print header/footer * copies the visible legend into the print view Important: These files are loaded with Jekyll {% include %} because they currently live under /_includes/assets/js/... rather than the public /assets/js/... folder. If these files are later moved into the public assets folder, this file should be changed to standard ...script> tags instead. {%- endcomment -%}
